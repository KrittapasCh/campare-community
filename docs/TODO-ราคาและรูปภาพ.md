# สิ่งที่ต้องทำต่อ — ราคาและรูปภาพ

เอกสารนี้ไว้ให้ใครก็ได้ในทีมหยิบไปทำต่อโดยไม่ต้องมาถาม

---

## สถานะตอนนี้

| | สถานะ |
|---|---|
| สินค้าในระบบ | 3,874 รุ่น (กล้อง 3,869) |
| มีรูป | 3,857 รุ่น — จาก CameraDatabase ผ่าน jsDelivr |
| **มีราคา** | **17 รุ่น** — 14 จาก seed + 3 ที่ค้นมา |
| มีแหล่งอ้างอิงราคา | 3 รุ่น |

ดูของจริงได้ตลอดด้วยคำสั่งนี้ใน Supabase SQL Editor

```sql
select count(*) filter (where msrp is null)                  as "ยังไม่มีราคา",
       count(*) filter (where msrp is not null)               as "มีราคาแล้ว",
       count(*) filter (where price_source_url is not null)   as "มีแหล่งอ้างอิง",
       count(*) filter (where thumbnail_url is null)          as "ยังไม่มีรูป"
from products where is_deleted = false;
```

## งานที่ 1 — เก็บราคา

### เป้าหมาย

ไม่ต้องครบ 3,869 รุ่น — **เอา 20–30 รุ่นที่คนรู้จักก็พอ** เพราะ

- รุ่นที่เหลือส่วนใหญ่เลิกผลิตไปสิบกว่าปีแล้ว ไม่มีราคาป้ายให้อ้างอิงอยู่แล้ว
- ราคาที่ไม่มีแหล่งอ้างอิงมีค่าน้อยกว่าไม่มีราคา เพราะถ้าโดนจับได้ว่าผิดจะเสียความน่าเชื่อถือทั้งระบบ

### เอารุ่นไหนก่อน

รันคำสั่งนี้เพื่อดูรายชื่อรุ่นที่ยังผลิตอยู่และยังไม่มีราคา — ไล่จากบนลงล่าง

```sql
select p.slug, c.name || ' ' || p.name as ชื่อเต็ม, p.release_year
from products p join companies c on c.id = p.company_id
where p.status = 'in_production'
  and p.msrp is null
  and p.is_deleted = false
order by p.release_year desc, c.name, p.name;
```

### หาราคาจากไหน

เรียงตามความน่าเชื่อถือ

1. **เว็บผู้ผลิตในไทย** — `sony.co.th`, `th.canon`, `nikon.co.th`, `fujifilm.com`
2. **ร้านตัวแทนจำหน่าย** — BigCamera, ZoomCamera, Digital2home, EC-Mall
3. **ข่าวเปิดตัวจากสื่อไทย** — beartai มักลงหัวข้อ "เปิดราคาไทย ..." ซึ่งเป็นราคาเปิดตัวอย่างเป็นทางการ

**ห้ามใช้** เว็บประกาศขายมือสองเป็นแหล่งราคาป้าย เพราะนั่นคือราคาตลาด ไม่ใช่ราคาเปิดตัว
(ราคามือสองระบบคำนวณเองอยู่แล้วจากประกาศขายจริงในเว็บเรา)

### วิธีที่เร็วที่สุด

เปิด BigCamera เว็บเดียว ค้นชื่อรุ่นทีละตัว จดราคากับ URL ของหน้านั้น
ประมาณ 20 รุ่นใช้เวลาไม่เกินครึ่งชั่วโมง

### กรอกที่ไหน

เปิดไฟล์ `supabase/migrations/0014_product_prices.sql` เติมบรรทัดในส่วน `values`

```sql
('slug-ของรุ่น', ราคา, 'URL ที่เปิดดูจริง', 'YYYY-MM-DD', 'opened'),
```

ตัวอย่าง

```sql
('fujifilm-x-t5', 62900, 'https://www.bigcamera.co.th/fujifilm-x-t5', '2026-09-15', 'opened'),
('sony-a6700',    54900, 'https://www.bigcamera.co.th/sony-a6700',    '2026-09-15', 'opened'),
```

แล้วรันไฟล์ทั้งไฟล์ใน SQL Editor — **รันซ้ำได้ ไม่กระทบแถวอื่น**

### กติกาที่ห้ามละเมิด

- **ห้ามเดา** ถ้าหาไม่เจอก็ข้ามรุ่นนั้นไป ปล่อยว่างดีกว่าใส่เลขมั่ว
- **URL ต้องเปิดได้จริง** และต้องเห็นตัวเลขนั้นในหน้านั้น — ไม่ใช่ URL หน้าแรกของร้าน
- **`opened`** = คุณเปิดหน้าอ่านเอง · **`listed`** = เห็นจากที่อื่นยังไม่ได้เปิด
  แถวที่เป็น `listed` ต้องมีคนไปกดยืนยันก่อนถึงจะใช้ตอนนำเสนอได้
- ใส่ `price_checked_at` เป็นวันที่ตรวจสอบจริง ไม่ใช่วันที่เปิดตัวสินค้า

## งานที่ 2 — รูปภาพ

### สถานะ

รูป 3,857 รุ่นมาจาก [CameraDatabase](https://github.com/leavestylecode/CameraDatabase) (MIT)
เสิร์ฟผ่าน jsDelivr โดยไม่ต้องเก็บไฟล์เอง — **ใช้งานได้อยู่แล้ว ไม่ใช่งานเร่งด่วน**

### ความเสี่ยงที่ควรจัดการ

**1. URL ผูกกับ `@main` ซึ่งขยับได้** — ถ้าเจ้าของ repo ย้ายไฟล์ รูปพังทั้งหมดพร้อมกัน

แก้ด้วยการผูกกับ commit ที่ไม่ขยับ

```sql
update products
set thumbnail_url = replace(thumbnail_url, '@main/', '@374a630/')
where thumbnail_url like '%cdn.jsdelivr.net%';
```

แล้วแก้ใน `0011_import_camera_database.sql` ให้ตรงกันด้วย

**2. repo ต้นทางอาจถูกลบ** — แก้ด้วยการ **fork** repo มาเป็นของเราเอง
(GitHub → หน้า repo → ปุ่ม Fork) แล้วเปลี่ยน URL ให้ชี้มาที่ fork ของเรา
ต้องแก้ `next.config.ts` ตรง `pathname: "/gh/leavestylecode/**"` ให้เป็นชื่อบัญชีเราด้วย

### ถ้าอยากได้รูปคุณภาพดีขึ้น

รูปจากชุดข้อมูลเป็นภาพสินค้าขนาดเล็ก ถ้าจะเปลี่ยนเป็นภาพจากผู้ผลิต
ทำเฉพาะรุ่นเด่น ๆ ที่จะใช้โชว์ตอนนำเสนอก็พอ (10–15 รุ่น)

1. โหลดภาพจากหน้าผู้ผลิต
2. อัปขึ้น Supabase → **Storage** → bucket `gallery` (หรือสร้าง bucket `products` ใหม่)
3. `update products set thumbnail_url = 'URL จาก Storage' where slug = '...';`

> **อย่าเอารูปใส่ repo โปรเจกต์** — ไฟล์จำนวนมากทำให้ Vercel build ช้าลงมาก
> โดยไม่ได้ประโยชน์อะไรกลับมา

## ถือว่าเสร็จเมื่อ

- [ ] รุ่นที่ยังผลิตอยู่มีราคาอย่างน้อย 20 รุ่น ทุกแถวเป็น `opened`
- [ ] ไม่มีแถวไหนที่มี `msrp` แต่ไม่มี `price_source_url`
- [ ] เปิดหน้าสินค้าแล้วเห็นลิงก์ "ที่มาราคา" กดได้จริง
- [ ] URL รูปผูกกับ commit ที่ไม่ขยับ หรือชี้มาที่ fork ของเราแล้ว
- [ ] อัปเดตตัวเลขในหัวข้อ "สถานะตอนนี้" ของเอกสารนี้ให้ตรงกับความจริง

ตรวจข้อสองด้วยคำสั่งนี้ — ต้องได้ 0 แถว

```sql
select slug, name, msrp from products
where msrp is not null and price_source_url is null and is_deleted = false;
```
